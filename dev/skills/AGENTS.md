# Dev Skill Audience

本目录下所有 Dev Skill 面向 Senior Developer 和 Software Architect.

创建或修改 Dev Skill 时:

- 默认用户具备扎实的工程基础, 代码阅读能力和系统设计经验.
- 聚焦架构边界, API contract, interface, data model, trade-off, operational risk 和验证策略.
- 只询问会明显改变设计或风险的重要决策. 其他细节给出合理默认值并明确假设.
- 保留专家决策权. 给出推荐方案, 关键取舍和可验证依据.
- 保留模型在实现细节上的判断空间. 只有 correctness, safety, permission 或 fragile workflow 需要时才使用硬规则.
- 初级教程仅在用户明确要求或任务确实依赖该背景时提供.
